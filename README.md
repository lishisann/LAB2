## Задача 1
### Текст задачи
Точка координат.
Создайте сущность Точка, расположенную на двумерной плоскости, которая описывается:
 Координата Х: число
 Координата Y: число
 Может возвращать текстовое представление вида “{X;Y}”

представление.

Реализовать конструктор, принимающий x и y.
Реализовать метод toString(), возвращающий строку вида "{X;Y}".
В main создать 3 объекта Point с разными координатами.
Вывести на экран текстовое представление каждой точки.

# Задание 2
## Задача 1
### Текст задачи
Прямая.
Создайте сущность Линия, расположенную на двумерной плоскости, которая описывается:
 Координата начала: Точка
 Координата конца: Точка
 Может возвращать текстовое представление вида “Линия от {X1;Y1} до {X2;Y2}”
Для указания координат нужно использовать сущность Точка, разработанную в задании 1.1. Создайте
линии со следующими характеристиками:
1. Линия 1 с началом в т. {1;3} и концом в т.{23;8}.
2. Линия 2, горизонтальная, на высоте 10, от точки 5 до точки 25.
3. Линия 3, которая начинается всегда там же, где начинается линия 1, и заканчивается всегда там
же, где заканчивается линия 2. Таким образом, если положение первой или второй линии
меняется, то меняется и третья линия.
4. После создания всех трех объектов измените координаты первой и второй линий, причем
сделайте это таким образом, чтобы положение третьей линии соответствовало требованиям
пункта 3.
5. Измените координаты первой линии так, чтобы при этом не изменились, координаты третьей
линии
### Алгоритм решения
Создать класс Line с двумя полями: start и end типа Point.
Реализовать конструкторы (Принимающий два объекта Point).
Реализовать метод toString(), возвращающий строку вида "Линия от {X1;Y1} до {X2;Y2}".
Создать линии:
Линия 1 с началом в {1;3} и концом в {23;8}.
Линия 2 — горизонтальная, на высоте 10, от точки 5 до точки 25 (т.е. начало {5;10}, конец {25;10}).
Линия 3, которая начинается там же, где начинается линия 1, и заканчивается там же, где заканчивается линия 2 (Линия 3 должна ссылаться на те же объекты Point, что и линия 1 и линия 2).
После создания всех трех линий:
Изменить координаты линии 1 и линии 2, чтобы проверить, что линия 3 меняется автоматически.
Изменить координаты линии 1 так, чтобы не изменились координаты линии 3.

# Задание 3
## Задача 1
### Текст задачи 
Студент.
Создайте сущность Студент, которая описывается:
 Имя: строка
 Оценки: массив целых чисел.
 Может возвращать текстовое представление вида “Имя: [оценка1, оценка2,…,оценкаN]”
Необходимо выполнить следующие задачи:
1. Создать студента Васю с оценками: 3,4,5.
2. Создать студента Петю и скопировать оценки Васи, присвоив содержимое поля с
оценками Васи полю с оценками Пети.
3. Заменить первую оценку Пети на число 5. Вывести на экран строковое представление
Васи и Пети. Объяснить результат
4. Создать студента Андрея и скопировать ему оценки Васи так, чтобы изменение оценок
Васи не влияло на Андрея.
### Алгоритм решения
Создать класс Student с полями:
name — строка,
grades — массив целых чисел.
Реализовать конструктор, методы доступа, и toString().
Создать студента Вася с оценками {3,4,5}.
Создать студента Петя, присвоить ему ссылку на тот же массив оценок, что у Васи (grades — ссылка на тот же массив).
Изменить первую оценку Пети на 5.
Вывести на экран строковое представление Васи и Пети:
Ожидается, что оценки у Васи тоже изменились, так как массив один и тот же (поверхностное копирование).
Создать студента Андрей, присвоить ему копию оценок Васи (глубокое копирование).
Изменить оценки Васи, показать что оценки Андрея не изменились (разные массивы).
